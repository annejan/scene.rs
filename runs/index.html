    The recording
    Chrome or Edge, the badge in BadgeLink mode (the purple diamond).

      What it is

      Only the maintainer sees a bug report. The recording lets them play your run back exactly as it went, so record from just before it goes wrong.

      The replay is Portals' own code (tests/host_runcheck.c), one build for each physics. A run that does not reach every exit it names, or was made on another physics, is said so and not listed. A badge-recorded run counts as a real run on trust and its video; scripted ones are always TAS.
